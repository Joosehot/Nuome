### prove 1 + 2 + ... + n = n(n + 1)/2

      1 + 2 + ... + n = n(n + 1)/2

        Base case n = 1: the sum is its first term, 1, and the formula gives (1 * 2)/2 = 1.
        Hypothesis: for some n >= 1, 1 + 2 + ... + n = n(n + 1)/2.
        Step: the sum up to n + 1 is the sum up to n plus the next term n + 1;
          by the hypothesis that is n(n + 1)/2 + n + 1, which must equal the formula at n + 1:
      n(n + 1)/2 + n + 1 = (n + 1)(n + 2)/2
  2.  Multiply n into the brackets.   [distribute]
      (n^2 + n)/2 + n + 1 = (n + 1)(n + 2)/2
  3.  Multiply each term of n + 1 by each term of n + 2.   [multiply_out]
      (n^2 + n)/2 + n + 1 = (n^2 + 2n + n + 2)/2
  4.  Multiply both sides by 2, the least common denominator.   [clear_denominators]
      n^2 + n + 2n + 2 = n^2 + 2n + n + 2
  5.  Both sides are the same: n^2 + n + 2n + 2.   [sides_equal]
      proved
